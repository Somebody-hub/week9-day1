## День 1 (JUnit 5 без Spring)

### Реализованная функциональность и тесты:

1. **`DiscountCalculator`**
    * Реализован точный расчет скидки с использованием `BigDecimal`.
    * Покрыто **5 стандартных сценариев** (включая дробные проценты и банковское округление `HALF_UP`).
    * Проверены граничные случаи: ноль, отрицательные значения, максимум (100%) и валидация выхода за допустимый диапазон `[0, 100]`.

2. **`TaskDurationParser`**
    * Разработан парсер строковой оценки времени в стиле Jira (`d`, `h`, `m`) с поддержкой составных строк (например, `"2d 4h 30m"`).
    * Протестированы успешные сценарии разбора, а также граничные условия: `null`, пустая строка `""`, строки из пробелов и табуляций.
    * Невалидный формат, отрицательные значения и ноль минут проверяются через `assertThrows` с проверкой типа `IllegalArgumentException`.

3. **`TaskStatus`**
    * Полная матрица всех **16 пар переходов** между состояниями покрыта **одним параметризованным тестом** с использованием `@CsvSource` (колонки: `from`, `to`, `expected`).
    * Отдельным тестом проверен запрет перехода в `null`.

---

### Проверка красного цикла (Red-Green):
* Проведена проверка на устойчивость к мутациям кода: при искусственном отключении перехода `DONE -> CANCELED` падает ровно 12-й сценарий параметризованной матрицы:
  > `[12] Переход DONE -> CANCELED разрешен: true`  
  > `expected: <true> but was: <false>`
